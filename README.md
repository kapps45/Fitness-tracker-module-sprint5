# 🏃 Fitness Tracker

Go-модуль для обработки данных о физической активности и расчёта основных показателей тренировок.

Проект использует структуры, методы и интерфейсы Go для работы с разными видами активности и разделяет вычисления по отдельным пакетам.

## 🔧 Возможности

- 📏 Расчёт пройденного расстояния
- ⚡ Определение средней скорости движения
- 🔥 Расчёт расхода энергии
- 👤 Обработка персональных параметров пользователя
- 🏃 Работа с тренировками и дневной активностью
- 📊 Форматирование результатов тренировок
- 🔄 Единый подход к обработке разных видов активности

## 📦 Основные компоненты

| Пакет | Назначение |
|---|---|
| `actioninfo` | Интерфейс и вывод общей информации об активности |
| `daysteps` | Обработка данных о шагах и дневной активности |
| `personaldata` | Работа с параметрами пользователя |
| `spentenergy` | Расчёт дистанции, скорости и энергозатрат |
| `trainings` | Обработка и форматирование данных тренировок |

## 🚀 Запуск

Для запуска приложения выполните:

    go run ./cmd/tracker

## 🧪 Тестирование

Для основных пакетов проекта предусмотрены автоматизированные тесты.

Запуск всех тестов:

    go test ./...

Проверка покрытия:

    go test -cover ./...

## 🎯 Цель проекта

Практика объектно-ориентированного подхода в Go с использованием структур, методов, интерфейсов и композиции, а также организация кода по отдельным пакетам с автоматизированным тестированием.
